# Showcase Summary

This repository is a public scientific-computing demo for exploring a
reduced-order atomizing-jet model in the browser. It is most useful as evidence
of domain-grounded technical communication, reproducible interactive demos, and
careful model-evaluation habits.

Live app: https://ferminfm.github.io/ideal-momentum-jet-explorer/

Source repo: https://github.com/ferminfm/ideal-momentum-jet-explorer

## Recruiter-Relevant Fit

### Google AI / DeepMind Direction

- Demonstrates scientific model inspection, numerical edge-case handling, and
  explicit distinction between model output, synthetic examples, and validation.
- Provides visual and physical-system reasoning evidence through interactive
  2D/3D plots, normalized variables, dimensional inputs, and exportable sampled
  states.
- Shows multilingual technical-product instincts through English, Japanese, and
  Spanish interface controls and documentation-ready explanations.

### Google Cloud Developer Advocate Direction

- Offers a public, runnable demo that can support workshops, notebooks,
  sample-style code walkthroughs, and technical writing for scientific and
  industrial AI audiences.
- Uses a practical static deployment model: React, TypeScript, Vite, GitHub
  Pages, browser-side CSV import/export, report generation, and no backend
  service dependency.
- Includes a repeatable QA loop: unit tests, lint, production build, asset
  reporting, and visual smoke checks.

## What To Demonstrate In A Short Review

1. Open the live app and select a quick-start example.
2. Change nozzle geometry, density ratio, or spreading angles and inspect how
   area, velocity, density, pressure, and entrainment curves respond.
3. Use the 3D view to connect the visual geometry to the normalized state
   variables.
4. Export sampled CSV data or generate a browser-side technical report.
5. Point to the README caveats to show that the project separates exploratory
   modeling from engineering validation.

## Important Boundaries

This app is not validated engineering design software, not a CFD replacement,
not a full spray simulation, and not an AI model. Its showcase value is the
public packaging of scientific reasoning, reproducible interaction, and
developer-facing explanation.
